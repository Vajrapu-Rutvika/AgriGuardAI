# AgriCompanion Pro

Build a new full-stack web application called "AgriGuard AI".

AgriGuard AI is a farmer-friendly, multilingual and voice-enabled AI farming companion.

IMPORTANT:

Build a REAL working website, not a static UI mockup.

Use a proper frontend, backend/API architecture and database.

Keep all secrets in environment variables.

Use reusable components and modular architecture.

The application must be a WEBSITE and fully responsive on:

- mobile

- tablet

- desktop

==================================================

DESIGN SYSTEM — APPLY TO THE ENTIRE APPLICATION

==================================================

The entire website must have a premium Indian farming + village visual identity.

It should feel like:

"A trusted digital farming companion for a farmer."

NOT like:

- generic SaaS

- futuristic AI dashboard

- banking application

- medical dashboard

- generic chatbot

Visual inspiration:

- green crop fields

- paddy fields

- vegetable farms

- village pathways

- subtle rural houses

- trees

- irrigation/water canals

- soil

- farming tools

- sunrise

- crop leaves

- subtle farmer/farm illustrations

Use these elements tastefully. Do not overcrowd the UI.

Color system:

- agricultural deep green

- leaf green

- warm cream/off-white

- sage green

- earthy brown

- natural harvest yellow

- soft sky blue for weather

- green for safe

- orange for warning

- red for danger

Avoid neon colors and excessive gradients.

Typography must be:

- highly readable

- large enough for farmers

- accessible

- compatible with Telugu, Hindi and English

Use semantic HTML, good contrast, large touch targets and responsive layouts.
